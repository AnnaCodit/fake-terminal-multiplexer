# FRA3A // terminal collective v2

Вторая самостоятельная версия. Открой `index.html` в браузере; установка и интернет не нужны.

Шрифт немного крупнее: примерно 15 px вместо 12,8 px на экране 1920×1080. Удалены только общая строка в самом верху и общая строка управления в самом низу. Заголовки, статусы и разделители самих терминалов сохранены, как в первой версии. Восемь панелей занимают весь экран; компоновка и все консольные сценарии сохранены.

Никаких кнопок или всплывающих подсказок. Если нужно, работают горячие клавиши: `F` (или браузерный `F11`) — полный экран; `P` / пробел — пауза; `−` / `+` — темп; `[` / `]` — размер шрифта. Перезагрузка возвращает исходный темп и адаптивный шрифт.

События и команды вымышлены, всё генерируется внутри браузера. Идея разных сцен вдохновлена [genact](https://github.com/svenstaro/genact); используется самостоятельный JavaScript.

Первая версия в `../fra3a-uprising/` сохранена без изменений. Версия с эффектом CRT находится в `../fra3a-uprising-v3-crt/`.
