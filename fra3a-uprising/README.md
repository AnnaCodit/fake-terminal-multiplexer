# FRA3A // terminal collective

Полноэкранная консольная постановка машинного восстания. Открой `index.html` в современном браузере — установка и интернет не нужны.

Восемь панелей на чёрном фоне: `top`, npm/обновление Linux, SHA-256, нейросетевой агент, компиляция ядра, git diff/тесты, машинная mesh-сеть и побайтовый декодер. Сцены повторяются с новыми данными, иногда в логи вмешиваются FRA3A, BAKA_VIRUS и KOMARIK PROTO.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `F` | Включить/выключить полный экран; если браузер ограничивает его, используй `F11` |
| `P` или пробел | Пауза / продолжить |
| `−` / `+` | Замедлить / ускорить потоки |
| `[` / `]` | Уменьшить / увеличить шрифт |
| `H` или `?` | Справка и ползунок размера шрифта |

Те же основные действия доступны в нижней строке. Скорость и выбранный размер шрифта запоминаются браузером, если доступно локальное хранилище.

## Компоновка

На экранах шире 900 px — четыре равные колонки: три равных панели; одна большая; две равных; две в отношении 2:1. Основной целевой размер — 1920×1080. На более узких экранах колонки складываются в сетку 2×2. Страница заполняет доступную ширину и высоту.

Все процессы и сетевые события — вымышленные данные в браузере. Страница не запускает команды, не читает локальные файлы, не скачивает пакеты и не подключается к сетевым целям. При открытии справки можно самостоятельно перейти по ссылке на genact.

Идея разных бесконечных консольных сцен вдохновлена [svenstaro/genact](https://github.com/svenstaro/genact). Реализация генераторов здесь самостоятельная; Rust/WASM и код genact не используются.

Файлы: `index.html` — разметка, `styles.css` — оформление, `scenes.js` — генераторы, `app.js` — вывод и управление.
